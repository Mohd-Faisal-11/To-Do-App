# 📝 To-Do App

A simple and interactive **To-Do List web application** built using **HTML, CSS, and JavaScript**.
It allows users to add, manage, and remove tasks through a clean and user-friendly interface.

## ✨ Features

* ➕ Add new tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 📱 Responsive design
* 🎨 Clean and simple user interface
* ⚡ Fast and lightweight
* 🖱️ Interactive task management using JavaScript

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and responsive design
* **JavaScript** — Functionality and DOM manipulation

## 💻 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Mohd-Faisal-11/To-Do-App.git
```

### 2. Open the project folder

```bash
cd To-Do-App
```

### 3. Run the project

Open `index.html` in your browser.

You can also use **Live Server** in VS Code for a better development experience.
